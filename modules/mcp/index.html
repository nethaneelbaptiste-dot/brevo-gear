Before you run

  • Create a Restricted key in Brevo (Settings, SMTP & API), give it only the resources you need, switch on "Create MCP server API key", and use the MCP token (starts with eyJ), not the xkeysib- key. Never paste keys in chat.
  • Prompts and everything the tools return are sent to Anthropic's API, and this connector is not eligible for zero data retention. Check your data policy before using real contact data.
  • Read-only mode only attaches read tools. Whether Brevo also refuses writes for a Read-only key is still to be verified with a harmless test.
  • Calls go from your browser to api.anthropic.com and mcp.brevo.com. If a request fails with a network error, check the browser console (CORS) and report it: this has not been verified from this host yet.
