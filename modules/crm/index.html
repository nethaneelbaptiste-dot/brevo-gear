Before you run

  • API keys stay in the tab's memory. Do not paste them in chat.
  • Deleting is offered only on attributes whose type differs, and needs a typed confirmation.
  • Custom objects need an Enterprise or Pro plan. The custom object tool infers the model from records and creates nothing.
  • Delete all records has no undo and removes the records' associations. Run the dry run first.
  • Check the rate-limit tier of each account first. The Default tier can answer 429 for minutes.
